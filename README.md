# SupeRR Selector S2 – Pressure Ratings dashboard
Run locally: `pip install -r requirements.txt && streamlit run app.py`
Deploy free: push this folder to a public GitHub repo -> https://share.streamlit.io -> New app -> main file `app.py` -> copy the link into the Unstop dashboard field.
`analysis/` holds the scripts (step1..step10) that regenerate every number from the data pack.
